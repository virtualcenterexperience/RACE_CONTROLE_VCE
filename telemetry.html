INTEROPÉRABILITÉ

Format d'échange VCE JSON : session, jeu, voiture, circuit, tours, échantillons horodatés (position GPS ou XY, accélérateur, frein, volant, vitesse, rapport, glisse). Les imports MoTeC natifs nécessiteront un convertisseur côté application : le navigateur ne lit pas directement les fichiers propriétaires.

Les deltas par secteur sont calculés à partir des temps sectoriels fournis. Les comparaisons ne sont valables que pour un même circuit, une même configuration et des tours propres. Le tour idéal est la somme des meilleurs secteurs valides disponibles.
