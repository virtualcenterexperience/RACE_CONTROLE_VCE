FONCTIONNEMENT DE LA SYNCHRONISATION

1. L'application identifie le jeu et propose l'association du PC. 2. Le STAFF vérifie et approuve la correspondance pilote / GUID. 3. Une API authentifiée reçoit les sessions et les associe à l'appareil autorisé. 4. Les tours apparaissent sur le dashboard du pilote avec les autorisations appropriées.

Les appareils révoqués doivent perdre leur accès API immédiatement. Aucun secret serveur ne doit être placé dans l'application publique ou dans GitHub Pages.
