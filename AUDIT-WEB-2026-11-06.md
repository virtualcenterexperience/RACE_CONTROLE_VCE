# Audit web VCE RACE CONTROL — 6 novembre 2026

## Périmètre
Vérification statique du dépôt GitHub (branche `main`) : **36 pages HTML**, **4 feuilles CSS**, **27 scripts JavaScript** côté web. Contrôles effectués : syntaxe des scripts JavaScript et des scripts intégrés aux pages, doublons d'identifiants HTML, équilibre des principales balises, références locales des images et scripts, et équilibre des blocs CSS.

Cet audit **n'est pas un test fonctionnel en navigateur connecté à Supabase** ; aucune session pilote réelle n'était disponible. Les 2 fonctions TypeScript, 12 scripts Python (application Windows) et 17 fichiers SQL ne font pas partie de ce contrôle web approfondi.

## Corrections appliquées
- Séparation des modules : `telemetry-navigation.js` charge les scripts **Tour uniquement dans Tour**, et les scripts **Setup uniquement dans Setup**. Panneaux Tour cachés de la vue Setup.
- Correction de la syntaxe qui empêchait l'exécution de `telemetry-setup-studio.js`, `telemetry-staff.js`, `overlay-resultats.js` et du script interne de `telemetry.html`.
- Réparation d'une balise de section superflue dans `evaluations-staff.html`.
- Réutilisation du **logo VCE ESPORT réellement présent** : `data/images/Design_sans_titre_2-removebg-preview.png` pour les overlays calendrier, lineup et résultats. Aucun logo créé artificiellement.
- Historique des tours **valides et invalides** harmonisé entre récapitulatif, comparaison, replay, sélection Tour et analyse avancée. Le meilleur tour automatique utilise uniquement un chrono valide.
- Correction du chargement Supabase : l'Edge Function `get_laps` limite chaque réponse à **8 tours**. Le site récupère désormais plusieurs pages (`before_lap`), jusqu'à **40 tours récents** par session chargée automatiquement. Le bouton « Charger les tours précédents » reste disponible.
- Transfert côté navigateur des canaux mécaniques facultatifs uniquement lorsqu'ils sont présents dans les mesures ; aucune mesure simulée.
- Correctifs d'affichage, couleurs VCE bleu/rouge et indicateurs frein (rouge) / accélérateur (vert).
- Ajout du logo existant et actualisation de la description du salon de télémétrie.

## Reste à tester avec une session réelle

4. Contrôle et import des futurs dossiers de chronos, voitures, circuits et sessions fournis par l'équipe.
5. Vérification visuelle de la publication GitHub Pages. Les pages publiques n'ont pas pu être consultées depuis l'outil de navigation durant cet audit ; les modifications sont confirmées par les commits du dépôt GitHub.
