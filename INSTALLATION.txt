VCE ESPORT — SYNCHRONISATION SUPABASE

1) Sur https://supabase.com : créer un projet.
2) SQL Editor : exécuter supabase-setup.sql.
3) Authentication > Users : créer un utilisateur STAFF avec son email et mot de passe.
4) Copier son UUID, puis exécuter dans SQL Editor :
   insert into public.vce_staff_users(user_id) values ('UUID_ICI');
5) Project Settings > API : récupérer Project URL et clé PUBLIQUE publishable/anon.
6) Les mettre dans vce-supabase-config.js. Ne JAMAIS utiliser service_role.
7) Copier les fichiers HTML/JS de ce ZIP à la RACINE du dépôt GitHub Pages.
   Garder les autres fichiers et les dossiers data/ existants.
8) Commit + push sur main, attendre le déploiement GitHub Pages.
9) Ouvrir resultats-staff.html, se connecter via email/mot de passe STAFF,
   remplir un résultat puis cliquer « Enregistrer pour tous » dans la zone
   5 PRESETS. Le bouton « Enregistrer » interne au formulaire ne publie
   qu'une prévisualisation locale ; le bouton « Enregistrer pour tous » publie.
10) Même principe pour calendrier-staff.html et lineup-staff.html.
11) Sur resultats.html, calendrier.html, lineup.html et pilote.html :
    lecture automatique toutes les 10 secondes (onglet actif).

IMPORTANT :
- La clé publique Supabase est conçue pour être visible : la sécurité des
  écritures est assurée par l'authentification et les règles RLS SQL.
- Le code de démonstration VCE-STAFF-2026 n'est PAS utilisé pour la base.
- Les points R de course (Safety Rating) sont recalculés à partir des résultats.
- Les points d'entraînement, XP et classes restent issus des séances ; ils
  ne sont PAS modifiés par les résultats de course (barèmes distincts).
- Pour que l'attribution fonctionne, les noms et prénoms des pilotes dans les
  résultats doivent correspondre aux identifiants/noms des profils.
- Les anciens JSON restent en secours lorsque Supabase n'est pas configuré.
- Nécessite un projet Supabase opérationnel ; impossible de créer le projet
  ou d'installer la base sans vos paramètres et autorisations.
- Cette intégration n'a pas été testée contre votre projet Supabase réel.
