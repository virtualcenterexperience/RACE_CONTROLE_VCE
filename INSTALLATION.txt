MODE STAFF SUR LES PROFILS — VCE ESPORT

INSTALLATION
1. Copier les 7 fichiers HTML/JS de ce dossier à la racine du dépôt.
   Remplacer pilote.html, calendrier-staff.html, resultats-staff.html,
   lineup-staff.html, vce-github-sync.js, vce-github-config.js,
   vce-pilot-sync.js ; ajouter vce-staff-mode.js.
2. IMPORTANT : les autres fichiers et le dossier data/ restent inchangés.
3. Dans vce-staff-mode.js, modifier la ligne :
   const PASSWORD='VCE-STAFF-2026';
   (code de démonstration).
4. git add . ; git commit ; git push
5. Ouvrir pilote.html, choisir un pilote et cliquer MODE STAFF en bas à droite.
   Entrer le code, puis utiliser Calendrier / Résultats / Lineup.
6. Les pages STAFF existantes permettent d'éditer les presets et
   d'EXPORTER les JSON. Pour partager, publier les JSON dans data/team/
   via GitHub. L'export n'envoie PAS les données automatiquement.

SÉCURITÉ ET LIMITES
Ce mot de passe est présent dans un fichier JavaScript PUBLIC : il peut être
lu par n'importe qui. Il masque seulement les commandes dans l'interface,
il ne constitue PAS une véritable sécurité ni un contrôle d'accès.
La protection des modifications réelles reste assurée par les droits GitHub.
Ne jamais y mettre un mot de passe réutilisé sur un autre service.
La session est mémorisée seulement dans l'onglet (sessionStorage).
GitHub Pages ne peut pas enregistrer des modifications directement.
Ce ZIP n'ajoute PAS de synchronisation automatique des résultats.
Ne pas confondre cette interface avec une authentification sécurisée.
