# Portraits des affiches Résultats TEAM

Utiliser l’identifiant du pilote dans l’effectif, par exemple `lucas-galy`.

Le studio reconnaît automatiquement les fichiers déposés dans `data/images/pilotes/<identifiant>/` et nommés `1.png` ou `2.png`. Les extensions `.webp`, `.jpg`, `.jpeg` et `.tga` sont également reconnues. Un fichier nommé `1` devient « Photo 1 » et un fichier nommé `2` devient « Photo 2 ».

Pour d’autres noms ou emplacements dans `data/`, compléter `index.json` avec, par exemple, `{"lucas-galy":["data/images/portraits/lucas-course.png","data/images/portraits/lucas-equipe.jpg"]}`.
